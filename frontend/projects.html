Unified L1 Copilot Platform

Tech Mahindra · RAG · MCP · Agent orchestration

Enterprise IT ops was fragmented across tools with high change-request volume and observability gaps causing manual triage fatigue. Built a centralized AIOps engine correlating infra monitoring, ITSM/CMDB, docs, and comms into one layer, with human approval before any production action.

Result: 4x faster MTTR, 2x faster change execution, IDR 79B+ annual revenue loss prevented, 20% weekly engineering time reclaimed.

YAML-based Terraform Standardization

PT HM Sampoerna Tbk. · Terraform · GitOps

Global compliance required GitOps provisioning via Terraform Enterprise, but legacy resources had inconsistent naming and environment drift. Replaced per-environment Terraform code with one codebase driven by per-environment YAML config, using for_each and TF_VAR_env injection.

Result: compliance without blocking operations; non-Terraform-expert engineers could safely edit YAML instead of HCL.

Multi-Tenant ECS Platform Migration

PT Telkom Indonesia Tbk · AWS ECS · Bitbucket CI/CD

Product had grown to 100+ single-tenant EC2 instances (one per client) — unsustainable cost and ops overhead. Redesigned onto a shared AWS ECS platform, migrated Singapore → Jakarta region, and added a DevSecOps-integrated CI/CD pipeline.

Result: ~70% AWS cost reduction, deploys cut from 10 to 5 minutes, no more per-client instance ceiling.
